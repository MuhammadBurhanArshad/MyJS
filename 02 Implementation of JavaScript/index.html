JavaScript Implementation

There are 2 ways to implement JavaScript in HTML:

  1. Internal — code inside <script> tag
  2. External — linked .js file

1. Internal JavaScript

Code is written directly inside the <script> tag inside <head>:

<html>
  <head>
    <script>
      console.log("Internal JS");
    </script>
  </head>
  <body> ... </body>
</html>

2. External JavaScript

Code lives in a separate .js file and is linked via src:

<html>
  <head>
    <script src="myScript.js"></script>
  </head>
  <body> ... </body>
</html>

⭐ Best Practice

Place <script> at the end of <body>:

<body>
  <h1>Hello</h1>
  <script src="myScript.js"></script>
</body>
