Array Method map()

Target

  • map() — transform each element of an array

Array-map() Function

⭐ map() is for changing the whole array.

Syntax

var newArray = arrayName.map(function (value) {
    statement
    return newValue;
});

Example

var a = [1, 3, 5, 8, 10];

a.map(x => x * 10);
// [10, 30, 50, 80, 100]

With Named Function

var ary = [11, 4, 9, 16];
var b = ary.map(test);

document.write(b);

function test(x) {
    return x * 10;
}

// Output: 110,40,90,160

map() with String

⭐ We can also use map() with string. 
var str = "Hello";
Array.from(str).map(ch => ch.toUpperCase());
// ["H", "E", "L", "L", "O"]
