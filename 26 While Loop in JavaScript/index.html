JavaScript While Loop

A loop is used to repeat a block of code multiple times.

Without Loop vs With Loop

❌ Without Loop

document.write("Burhan");
document.write("Burhan");
document.write("Burhan");

✅ With Loop

Loop (3 Times) {
    document.write("Burhan");
}

Loop is Divided in 3 Parts

Initialization
     ↓
┌───────────────┐
│  Condition    │  False → Out of Loop
└───────────────┘
     ↓ True
  Statement
     ↓
Increment / Decrement
     ↓ (back to Condition)

Types of Loops in JavaScript

  • While Loop
  • Do / While Loop
  • For Loop
  • For / In Loop (Objects)
  • For Each (Array)

While Loop Syntax in JavaScript

var a = 1;

while (a <= 10) {
    document.write("Yahoo Baba");
    a = a + 1;
}
⚠️ Always increment the loop variable — otherwise you will create an infinite loop.
