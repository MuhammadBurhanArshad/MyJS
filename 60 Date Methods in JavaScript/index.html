JavaScript Date Methods

JavaScript Date Object

var now = new Date();

How to Take Current Date

var now = new Date();
document.write(now);
// It takes the current date

Getter Methods

MethodDescription
toDateString()Readable date string
getDate()Day of month (1–31)
getFullYear()Year (e.g., 2022)
getMonth()Month (0–11)
getDay()Day of week (0–6)
getHours()Hours (0–23)
getMinutes()Minutes (0–59)
getSeconds()Seconds (0–59)
getMilliseconds()Milliseconds (0–999)

Setter Methods

MethodDescription
setDate()Sets the day of month
setFullYear()Sets the year
setMonth()Sets the month (0–11)
setHours()Sets hours
setMinutes()Sets minutes
setSeconds()Sets seconds
setMilliseconds()Sets milliseconds

1. toDateString() — Current Date

var now = new Date();
now.toDateString();
// "Tue Dec 28 2022"

2. getDate()

now.getDate();   // 28

3. getFullYear()

now.getFullYear();   // 2022

4. getMonth()

now.getMonth();   // 11  (December)
// Months count from 0

5. getDay()

now.getDay();   // 2  (Tuesday)
// Starts from Sunday = 0

6. getHours / getMinutes / getSeconds / getMilliseconds

now.getHours();        // 18
now.getMinutes();      // 27
now.getSeconds();      // 41
now.getMilliseconds(); // 938

Setter Examples

var now = new Date();

now.setDate(20);        // → Dec 20 2022
now.setFullYear(2023);  // → Dec 20 2023
now.setMonth(4);        // → May 20 2023
now.setHours(14);       // → 14:58:49
now.setMinutes(30);
now.setSeconds(15);
now.setMilliseconds(500);
⚠️ Months are 0-indexed (Jan=0, Dec=11).
⚠️ Days are 0-indexed (Sun=0, Sat=6).
⭐ getDate() → day of month (1–31).
⭐ getDay() → day of week (0–6).
