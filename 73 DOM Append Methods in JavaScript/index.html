DOM Append Methods

  • appendChild() — add as last child
  • insertBefore() — add before an existing child

1. appendChild — DOM Append Method

Appends a node as the last child of a parent.

Syntax

parentElement.appendChild(newNode);

Example

var newElement = document.createElement("h2");
var newText = document.createTextNode("Burhan");

newElement.appendChild(newText);

document.getElementById("test").appendChild(newElement);

console.log(newElement);

2. insertBefore — DOM Append Method

For appending an element, text, or comment before a target.

Syntax

parentElement.insertBefore(newNode, referenceNode);

Example

var newElement = document.createElement("h2");
var newText = document.createTextNode("This is just Text");

newElement.appendChild(newText);

var target = document.getElementById("test");

target.insertBefore(newElement, target.childNodes[0]);

appendChild vs insertBefore

FeatureappendChild()insertBefore()
PositionEnd of parentBefore a specific child
ArgumentsnewNodenewNode, referenceNode
Use caseAdd at endAdd at specific position

Visual

Parent │ ├── [child 1] ├── [child 2] ← existing children └── [child 3] After appendChild(newNode): ├── [child 1] ├── [child 2] ├── [child 3] └── [newNode] ← added at end After insertBefore(newNode, child 2): ├── [child 1] ├── [newNode] ← inserted before child 2 ├── [child 2] └── [child 3]
