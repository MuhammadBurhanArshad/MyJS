Const Variable with Array & Objects

Target

  • Understand const with Array
  • Understand const with Object
⭐ We can't assign const variable multiple times.

1. Const Variable with Array

Changing Array Value — ✅ Allowed

const a = [10, 20, 30];
a[1] = 25;

console.log(a);   // [10, 25, 30]

Reassigning the Whole Array — ❌ Not Allowed

const a = [10, 20, 30];
a = [1, 2, 3];   // ❌ TypeError

We cannot assign value as a whole variable.

2. Const Variable with Object

Changing Properties — ✅ Allowed

const a = {
    name: "Burhan",
    age: 18
};

a.name = "Burhan Arshad";
console.log(a);

Reassigning the Whole Object — ❌ Not Allowed

const a = { name: "Burhan" };
a = { name: "Aman" };   // ❌ TypeError

We can't assign value as normal to a const variable.

Summary Table

ActionArray (const)Object (const)
Modify elements / properties✅ Allowed✅ Allowed
Add elements / properties✅ Allowed✅ Allowed
Delete elements / properties✅ Allowed✅ Allowed
Reassign the whole variable❌ Not allowed❌ Not allowed

Why Does This Work?

const locks the binding, not the value.

  • Binding — the variable name pointing to a value.
  • Value — the actual array or object in memory.

The name must always point to the same value, but that value can still be modified.
