JavaScript Object Part II

Target Method — new Object()

  • new Object() — creates an empty object
  • Then we add properties using dot notation

Creating an Object — Method II

Step 1: Create an Empty Object

var a = new Object();

Step 2: Add Properties (Saving)

a.firstName = "Tom";
a.lastName = "Burhan";

Full Example

var a = new Object();
a.firstName = "Tom";
a.lastName = "Burhan";

document.write(a.firstName);   // Tom
document.write(a.lastName);    // Burhan

Calling / Accessing the Object

Three ways to access it:

1. console.log(a)

console.log(a);
// { firstName: "Tom", lastName: "Burhan" }

2. Dot Notation

document.write(a.firstName);
// Tom

3. Bracket Notation

document.write(a["firstName"]);
// Tom
⭐ All three ways produce the same data — they just display it differently.

Adding Properties Dynamically

var user = new Object();

user.name = "Burhan";
user.age = 18;
user.email = "burhan@example.com";

console.log(user);
// { name: "Burhan", age: 18, email: "burhan@example.com" }
