JavaScript Array of Objects

Target

  • Array having objects
  • Array of objects

Array of Objects — Syntax

var student = [
    { Name: "Burhan", Age: 18 },
    { Name: "Aman",   Age: 19 },
    { Name: "Rehman", Age: 20 }
];

Visual Layout

Index   Object
──────────────────────────────
  0     { Name: "Burhan", Age: 18 }
  1     { Name: "Aman",   Age: 19 }
  2     { Name: "Rehman", Age: 20 }

Accessing Values

student[0];          // { Name: "Burhan", Age: 18 }
student[0].Name;     // "Burhan"
student[1].Age;      // 19

Loop with for

for (var a = 0; a < student.length; a++) {
    document.write(student[a].Name + "<br>");
}

// Output:
// Burhan
// Aman
// Rehman

Loop with forEach

student.forEach(function (s) {
    document.write(s.Name + " - " + s.Age + "<br>");
});

// Output:
// Burhan - 18
// Aman - 19
// Rehman - 20

Loop with for...of

for (var s of student) {
    document.write(s.Name + "<br>");
}
