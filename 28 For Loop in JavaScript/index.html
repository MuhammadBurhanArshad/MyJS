JavaScript For Loop

Combines all 3 parts of a loop — initialization, condition, and increment/decrement — into a single line.

Syntax

for (initialization; condition; increment/decrement) {
    statement
}

The 3 Parts

for ( var a = 1 ;  a <= 10 ;  a++ )  {
      ↑              ↑          ↑
Initialization   Condition  Increment/Decrement
}
PartPurpose
InitializationRuns once, before the loop starts
ConditionChecked before each iteration
Increment / DecrementUpdates the loop variable after each iteration

Example

for (var a = 1; a <= 10; a++) {
    document.write("Burhan");
}

Prints "Burhan" 10 times.

Count 1 to 5

for (var i = 1; i <= 5; i++) {
    document.write(i + "<br>");
}

Count Down 10 to 1

for (var i = 10; i >= 1; i--) {
    document.write(i + " ");
}

Featureforwhile
