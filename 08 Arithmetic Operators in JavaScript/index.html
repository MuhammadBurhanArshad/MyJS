JavaScript Arithmetic Operators

Operators used to perform mathematical calculations on numbers.

Operators

OperatorDescription
+Addition
-Subtraction
*Multiplication
**Exponentiation
/Division
%Modulus (Remainder)
++Increment
--Decrement

Basic Example

var a = 20;
var b = 10;
var c = a + b;

document.write(c);   // 30

Division vs Modulus (14 ÷ 2)

         7      ← Division (/)
       ┌─────
     2 │ 14
       │ -14
       ──────
         0      ← Modulus (%)

Increment & Decrement

var x = 5;
x++;   // x becomes 6
x--;   // x becomes 5
