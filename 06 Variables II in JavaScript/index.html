JavaScript Variables (let & const)

Rules:

  • let cannot be declared twice.
  • var can be declared twice.
  • const is not editable or re-declarable.

Declaration Examples

var   a = "Burhan";
let   a = "Burhan";
const a = "Burhan";

Behavior Comparison

var

var x = "Hello";   ✅
var x = "World";   ✅ (redeclared)
x = "Wow";         ✅ (reassigned)

let

let x = "Hello";   ✅
let x = "World";   ❌ (redeclaration not allowed)
x = "Wow";         ✅ (reassigned)

const

const x = "Hello"; ✅
const x = "World"; ❌ (redeclaration not allowed)
x = "Wow";         ❌ (reassignment not allowed)
