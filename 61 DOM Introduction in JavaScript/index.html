JavaScript DOM Introduction

What is DOM?

  • DOM → Document Object Model
  • Represents the HTML document as a tree structure
  • Used by JavaScript to access and manipulate HTML elements

HTML DOM Tree

Document ↓ root (html) ├── element: <head> │ └── element: <title> │ └── text: "A New WebSide" └── element: <body> ├── element: <nav> │ └── text: "About Us" ├── element: <div> (attribute: class) └── element: <div> (attribute: id, class)

Node Types

Node TypeExample
Documentdocument
Element<div>, <h1>
Text"A New WebSide"
Attributeclass, id, href
⭐ These are Nodes — every part of the DOM is a node.

What Can We Do With the DOM?

We can do two types of work with the DOM tree in JavaScript:

  • Get — read values from the page
  • Set — modify values on the page

How to Access DOM Elements

document.getElementById("demo");
document.getElementsByClassName("box");
document.getElementsByTagName("p");
document.querySelector("#demo");

Common DOM Objects
