JavaScript Comparison Operators

Compare two values and return true or false.

Basic Example

var x = 15;
var y = 25;

x > y      // false

Different Types of Comparison Operators

OperatorDescription
==equal to
===equal value and equal type
!=not equal
!==not equal value or not equal type
>greater than
<less than
>=greater than or equal to
<=less than or equal to

== vs === 

5 ==  "5"   // true   (value only)
5 === "5"   // false  (value AND type)
5 !=  "5"   // false
5 !== "5"   // true
⭐ Best Practice: Prefer === and !== over == and != to avoid unexpected type coercion.
