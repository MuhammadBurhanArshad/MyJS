JavaScript DOM insertAdjacent Methods

DOM Append and Create Methods

  • insertAdjacentElement()
  • insertAdjacentHTML()
  • insertAdjacentText()

Uses

Tag — insertAdjacentElement()

[ Tag ] ↓ <p></p> ↓ insertAdjacentElement()

Tag with Text — insertAdjacentHTML()

[ Tag with Text ] ↓ <p>This is just text</p> ↓ insertAdjacentHTML()

Text — insertAdjacentText()

[ Text ] ↓ This is just text ↓ insertAdjacentText()

DOM insertAdjacent Positions

PositionWhere
"beforebegin"Before the element
"afterbegin"Inside, at start
"beforeend"Inside, at end
"afterend"After the element

Visual Positions

<!-- beforebegin --> <p id="target"> <!-- afterbegin --> ...existing content... <!-- beforeend --> </p> <!-- afterend -->

1. insertAdjacentElement()

Insert a DOM element.

var newElement = document.createElement("h2");
var newText = document.createTextNode("This is just text");

newElement.appendChild(newText);

var target = document.getElementById("test");

target.insertAdjacentElement("beforebegin", newElement);

2. insertAdjacentHTML()

Insert HTML string.

target.insertAdjacentHTML("beforeend", "<p>Appended via HTML</p>");
⚠️ Only use with trusted HTML — XSS risk otherwise.

3. insertAdjacentText()

Insert plain text.

target.insertAdjacentText("afterbegin", "Hello, world! ");
