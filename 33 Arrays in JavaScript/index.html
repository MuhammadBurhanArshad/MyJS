JavaScript Arrays

An array is a variable that holds multiple values.

Data Types in JavaScript

  • String
  • Number
  • Boolean
  • Array
  • Object
  • Null
  • Undefined

What is an Array?

❌ Wrong Ways

var a = 10, 20, 30;       // ❌ Error
var a = "10, 20, 30";     // ❌ String, not Array

✅ Correct Way

var a = [10, 20, 30];     // ✅ Array

How an Array Stores Values

var a = [10, 20, 30]
         0   1   2    ← index
IndexValue
010
120
230
⚠️ Indexing starts from 0, not 1.

Accessing Elements

var a = [10, 20, 30];

a[0]   // 10
a[1]   // 20
a[2]   // 30
a.length  // 3

Update a Value

var a = [10, 20, 30];
a[1] = 99;
// a → [10, 99, 30]
