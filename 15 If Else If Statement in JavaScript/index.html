JavaScript If Else If Statement

Used when there are more than two conditions. The first true condition wins.

Syntax

if (condition1) {
    // ...
} else if (condition2) {
    // ...
} else {
    // ...
}

Example — Greeting by Time

if (time < 10) {
    document.write("Good Morning");
} else if (time < 20) {
    document.write("Good day");
} else {
    document.write("Good evening");
}

Example Topic — Grade by Percentage

PercentageGrade
80 – 100%Merit
60 – 79%1st Division
45 – 59%2nd Division
33 – 44%3rd Division
Less than 33%Fail

Implementation

var percentage = 75;

if (percentage >= 80 && percentage <= 100) {
    document.write("Merit");
} else if (percentage >= 60 && percentage <= 79) {
    document.write("1st Division");
} else if (percentage >= 45 && percentage <= 59) {
    document.write("2nd Division");
} else if (percentage >= 33 && percentage <= 44) {
    document.write("3rd Division");
} else {
    document.write("Fail");
}
