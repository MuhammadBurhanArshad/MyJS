JavaScript Google Chrome Console

How to Open the Console

  1. Right-click on browser page
  2. Click Inspect (or press F12)
  3. Select the 2nd tab (Console)
The console is used for development purposes and for showing JavaScript errors. It can run all JavaScript commands.

Console Methods

1. console.log()

var x = 50;
console.log(x);

2. console.table()

console.table([1, 2, 3]);

3. console.error()

console.error("Something Wrong");

4. console.warn()

console.warn("Warning");

5. console.clear()

console.clear();

6. console.time() / console.timeEnd()

console.time("Test");
console.warn("Warning");
console.warn("Warning");
console.timeEnd("Test");

Summary Table

MethodPurpose
console.log()Print a message
console.table()Show data as a table
console.error()Show an error
console.warn()Show a warning
console.clear()Clear the console
console.time()Start a timer
console.timeEnd()Stop the timer
