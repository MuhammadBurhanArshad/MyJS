Variables in JavaScript

A variable stores a value and can be used multiple times.

Use of Variables

A = Burhan Arshad

document.write(A);
document.write(A);
document.write(A);

⚠️ No Commas Around Variable Names

document.write("Z");   ❌ prints letter Z (string)
document.write(Z);     ✅ prints value of variable Z

Three Types of Variables

KeywordDescription
varFunction-scoped, oldest way
letBlock-scoped, reassignable
constBlock-scoped, cannot be reassigned

How to Use Variables

<script>
  var x = "Burhan Arshad";
</script>
  • var → keyword
  • x → variable name
  • "Burhan Arshad" → variable value

Variable Naming

✅ Write Way:

  • firstname
  • first_name
  • first-name
  • firstName
  • firstname99

❌ Wrong Way:

  • first name (no spaces)
  • 99firstname (cannot start with a number)
