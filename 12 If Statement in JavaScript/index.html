JavaScript If Statement

Executes a block of code only when a condition is true.

Flow

If
 ↓
Condition
 ↓         ↘
True       False
 ↓           ↓
Statement    Out (skip)

Example (Conceptual)

If
 ↓
Today is Monday  →  False  →  Out
 ↓
True
 ↓
Print "Mon"

If Statement in JavaScript

if (condition) {
    statement;
}

Example

var x = 15;

if (x > 10) {
    document.write("x is Greater");
}

(Here we use a comparison operator inside the condition.)
