JavaScript DOM addEventListener()

HTML Event Attributes (Old Way)

<button onclick="abc()">Click me</button>
<img src="..." onmouseover="xyz()">
⚠️ But we want to add JavaScript in the JavaScript file.

Two Ways to Attach Events from JS

  1. Assign Events using the HTML DOM
  2. DOM addEventListener

1. Assign Events Using the HTML DOM

document.getElementById("header").onclick = abc;

function abc() {
    document.getElementById("header").style.background = "green";
}

2. DOM addEventListener()

document.getElementById("header").addEventListener("click", abc);

function abc() {
    document.getElementById("header").style.background = "green";
}

3 Parameters of addEventListener()

addEventListener(event, function, useCapture);
ParameterPurpose
eventEvent name, e.g., "click"
functionFunction to run when event fires
useCapturetrue (capture) / false (bubble, default)
⭐ Use Capture: true → capture phase; false → bubble phase.

Removing an Event Listener

element.removeEventListener("click", functionName);

Multiple Listeners on Same Event

var el = document.getElementById("header");

el.addEventListener("click", function () {
    console.log("First handler");
});

el.addEventListener("click", function () {
    console.log("Second handler");
});
