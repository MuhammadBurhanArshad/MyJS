JavaScript Nested Loop

When we use a loop inside a loop, it is called a nested loop (or multiloop).

Nested Loop Syntax

for (var a = 1; a <= 10; a++) {
    for (var b = 1; b <= 10; b++) {
        statement
    }
}

Example 1 — 3 × 3 Grid

for (var a = 1; a <= 3; a++) {
    for (var b = 1; b <= 3; b++) {
        document.write(a + "" + b + " ");
    }
    document.write("<br>");
}

Example 2 — Star Triangle

for (var a = 1; a <= 5; a++) {
    for (var b = 1; b <= a; b++) {
        document.write("*");
    }
    document.write("<br>");
}
