Array Method shift() & unshift()

Array Methods for Now

  • shift() — deletes the first value
  • unshift() — adds a value at the first position

1. shift() Method

Deletes the first value from an array.

Syntax

arrayName.shift();

Example

var a = ["Sanjay", "Aman", "Rehman", "Karan"];
a.shift();
// a → ["Aman", "Rehman", "Karan"]
IndexBeforeAfter
0"Sanjay""Aman"
1"Aman""Rehman"
2"Rehman""Karan"
3"Karan"—

2. unshift() Method

Adds a value at the first position of an array.

Syntax

arrayName.unshift(value);

Example

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
a.unshift("Arshad");
// a → ["Arshad", "Sanjay", "Aman", "Burhan", "Rehman"]
IndexBeforeAfter
0"Sanjay""Arshad"
1"Aman""Sanjay"
2"Burhan""Aman"
3"Rehman""Burhan"
4—"Rehman"
⭐ shift() deletes the first value of an array.
⭐ unshift() adds value at first of an array.
