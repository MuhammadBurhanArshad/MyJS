JavaScript Logical Operators

Used to combine multiple conditions in a single if.

Flow

If →  Condition 1
      Condition 2 → False → Out
         ↓
        True
         ↓
      Statement

Types of Logical Operators

OperatorName
&&Logical AND
||Logical OR
!Logical NOT

1. If Statement with Logical AND

if (condition1 && condition2) {
    // Run only when BOTH conditions are TRUE
}
C1C2Result

2. If Statement with Logical OR

if (condition1 || condition2) {
    // Run when EITHER one condition is TRUE
}

3. If Statement with Logical NOT

if (!(condition)) {
    // Runs when the condition is reversed
}
