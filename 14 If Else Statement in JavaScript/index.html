JavaScript If Else Statement

Extends if — runs one block for true and another for false.

Flow

If → Conditions → False → Statement
       ↓
      True
       ↓
    Statement

Syntax

if (condition) {
    // statement for TRUE
} else {
    // statement for FALSE
}

Example

var x = 15;

if (x > 30) {
    document.write("x is Greater");
} else {
    document.write("x is Smaller");
}

if vs if else

StructureWhen to use
ifRun code only if a condition is true; otherwise do nothing
if elseChoose between two alternatives
