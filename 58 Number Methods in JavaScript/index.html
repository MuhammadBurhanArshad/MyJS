JavaScript Number Methods

List of Number Methods

  • Number()
  • parseInt()
  • parseFloat()
  • isFinite()
  • isInteger()
  • toFixed()
  • toPrecision()

1. Number() — Convert to Number

Converts a value into a number. N of number should be Capital.

var a = "99";
var num = Number(a);

document.write(num + 10);   // 109

2. parseInt() — Convert to Integer

Converts a string number into an integer (removes decimals).

var a = "99.99";
var num = parseInt(a);

document.write(num);   // 99

3. parseFloat() — Extract Decimal Value

var a = "10.3";
var num = parseFloat(a);

document.write(num);   // 10.3

4. isFinite() — Check Finite Number

Returns true or false. Checks if a given value is finite or not.

var a = 100;
var num = isFinite(a);

document.write(num);   // true

5. isInteger() — Check Integer

Returns true or false. Checks if a given value is an integer.

var a = 10.50;
var num = Number.isInteger(a);

document.write(num);   // false

6. toFixed() — Round to Decimal Places

Returns rounded value to a given number of decimal places.

var a = 5.56789;
var num = a.toFixed(3);

document.write(num);   // 5.568

7. toPrecision() — Round to Significant Digits

Returns the rounded value of a given number of digits.

var a = 5.36789;
var num = a.toPrecision(2);

document.write(num);   // 5.4
