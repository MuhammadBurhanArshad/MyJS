Array Method pop() & push()

Array Methods for Now

  • pop() — removes the last value
  • push() — adds a value to the end

1. pop() Method

Removes the last value from an array.

Syntax

arrayName.pop();

Example

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
a.pop();
// a → ["Sanjay", "Aman", "Burhan"]
IndexBeforeAfter
0"Sanjay""Sanjay"
1"Aman""Aman"
2"Burhan""Burhan"
3"Rehman"(removed)

2. push() Method

Adds a value to the end of an array.

Syntax

arrayName.push(value);

Example

var a = ["Sanjay", "Aman", "Burhan"];
a.push("Rehman");
// a → ["Sanjay", "Aman", "Burhan", "Rehman"]
IndexBeforeAfter
0"Sanjay""Sanjay"
1"Aman""Aman"
2"Burhan""Burhan"
3—"Rehman"
⭐ pop() removes the last value.
⭐ push() adds a value to the end.
