JavaScript Arrays II

Another way to create arrays — using the new Array() constructor.

Another Way to Create Arrays

1. Old Way (Array Literal)

var a = [10, 20, 30];      // → old way

2. Another Way (new Array())

var a = new Array();       // → another way
We use new Array() for making an array when we don't have values to store in it.

Specifying the Size

var a = new Array(3);      // 3 empty slots

Important Note

new Array(3)            // length 3, empty array
new Array(10, 20, 30)   // [10, 20, 30]

Which Way Should You Use?

✅ Use the literal way [ ] in modern JavaScript.

⚠️ Only use new Array() when you specifically need to create an empty array with a fixed length.
