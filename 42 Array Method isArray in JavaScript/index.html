Array Method isArray()

Target Method

  • Array.isArray() — identify if a variable is an array

Array-isArray() Function

This function is used for identifying a variable — is that variable an array or not.

Syntax

Array.isArray(variable);

Return Values

InputReturns
An array [ ]true
A numberfalse
A stringfalse
An object { }false
nullfalse
undefinedfalse
⭐ It will return true or false.

Example

var a = ["Sanjay", "Aman", "Burhan"];
var b = 20;
var c = "Burhan";

Array.isArray(a);   // true
Array.isArray(b);   // false
Array.isArray(c);   // false

Store and Print

var a = ["Sanjay", "Aman", "Burhan"];

var result = Array.isArray(a);
document.write(result);

// Output: true

Why Use isArray()?

Because typeof returns "object" for both arrays and objects:

typeof [1, 2, 3]    // "object"
typeof { a: 1 }     // "object"   ← same!

Array.isArray([1, 2, 3])  // true
Array.isArray({ a: 1 })   // false
