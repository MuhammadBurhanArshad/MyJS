JavaScript String Methods II

Methods Covered

  • charAt(), charCodeAt(), fromCharCode()
  • concat(), split(), repeat()
  • slice(), substr(), substring()
  • toString(), valueOf()

1. charAt() — Value at Given Index

var str = "Burhan is a good boy";
str.charAt(3);
// "h"

2. charCodeAt() — Unicode at Index

var str = "Burhan is a good boy";
str.charCodeAt(4);
// 97  (Unicode of 'a')

3. fromCharCode() — Code to Character

String.fromCharCode(65);
// "A"

4. concat() — Join Strings

var str = "Burhan ";
var str2 = "Arshad";

str.concat(str2);
// "Burhan Arshad"

5. split() — String to Array

"Burhan Arshad".split(" ");
// ["Burhan", "Arshad"]

"a,b,c".split(",");
// ["a", "b", "c"]

"hello".split("");
// ["h","e","l","l","o"]

6. repeat() — Repeat String

"Burhan ".repeat(2);
// "Burhan Burhan "

7. slice() — Start & End

var str = "Burhan Arshad";
str.slice(1, 10);
// "urhan Arsh"

8. substr() — Start & Length

var str = "Burhan Arshad";
str.substr(3, 5);
// "han A"
⚠️ substr() is deprecated — prefer slice() or substring().

9. substring() — Start & End (exclusive)

var str = "Burhan Arshad";
str.substring(1, 5);
// "urha"

10. toString() — Convert to String

var str = 50;
str.toString() + 20;
// "5020"

11. valueOf() — Print Value

var str = "Burhan Arshad";
str.valueOf();
// "Burhan Arshad"

slice() vs substr() vs substring()

MethodParametersResult
slice(1, 10)start, end (exclusive)"urhan Arsh"
substr(3, 5)start, length"han A"
substring(1, 5)start, end (exclusive)"urha"
