Array Methods toString(), valueOf() & fill()

Target Methods

  • toString() — array to string
  • valueOf() — returns the array itself
  • fill() — fills with a static value

1. toString() Function

Used for changing an array to a string.

⭐ The toString() method converts an array into a string and returns the result.

Example

var a = ["Sanjay", "Aman", "Burhan"];
a.toString();
document.write(a);

// Output: Sanjay,Aman,Burhan

2. valueOf() Function

Returns the array itself.

Example

var a = ["Sanjay", "Aman", "Burhan"];
document.write(a.valueOf());

// Output: Sanjay,Aman,Burhan

3. fill() Function

Fills all the elements in an array with a static value.

Example

var a = ["Sanjay", "Aman", "Burhan"];
a.fill("Hello");
document.write(a);

// Output: Hello,Hello,Hello

Advanced — Fill with Start and End

var a = [1, 2, 3, 4, 5];
a.fill(0, 2, 4);
// a → [1, 2, 0, 0, 5]
