Array Methods concat() & join()

Target Methods

  • concat() — merge arrays
  • join() — convert array to string

1. concat() Method

Merges two or more arrays (or values) into a new array.

Syntax

var newArray = arrayName.concat(otherArray);
var newArray = arrayName.concat(value1, value2);
var newArray = arrayName.concat(array1, array2);

Example — Values

var a = ["Sanjay", "Aman", "Burhan"];
var c = a.concat("Karan", "Rehman");
// c → ["Sanjay", "Aman", "Burhan", "Karan", "Rehman"]

Example — Arrays

var a = ["Sanjay", "Aman", "Burhan"];
var b = ["Karan", "Rehman"];
var c = a.concat(b);
// c → ["Sanjay", "Aman", "Burhan", "Karan", "Rehman"]

Example — Multiple Arrays

var a = ["Sanjay"];
var b = ["Aman"];
var c = ["Burhan"];

var d = a.concat(b, c);
// d → ["Sanjay", "Aman", "Burhan"]
⭐ We can also put variable names in concat().
⭐ We can merge multiple variables.

2. join() Method

Converts an array into a string.

Syntax

var str = arrayName.join(separator);

Example — Custom Separator

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
var b = a.join(" - ");
// b → "Sanjay - Aman - Burhan - Rehman"

Example — Default Separator

["HTML", "CSS", "JS"].join();
// "HTML,CSS,JS"

Example — No Separator

["H", "e", "l", "l", "o"].join("");
// "Hello"
⭐ join() makes a String from the array.
