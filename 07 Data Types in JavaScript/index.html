JavaScript Data Types

A data type describes the kind of value a variable holds.

Example: var x = "Hello World"; → String

Different Types of Data

ValueData Type
"Hello World"String
25Number
trueBoolean
["HTML","CSS","JS"]Array → Object
{first:"Burhan",last:"Arshad"}Object
nullNull
var x;Undefined

Examples

var x = "Hello World";                    // String
var x = 25;                               // Number
var x = true;                             // Boolean
var x = ["HTML", "CSS", "JS"];            // Array → Object
var x = { first:"Burhan", last:"Arshad" };// Object
var x = null;                             // Null
var x;                                    // Undefined

typeof Operator

Used to find out the type of a variable's value:

document.write(typeof x);
