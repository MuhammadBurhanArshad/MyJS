JavaScript Prompt Box

Displays a popup dialog that asks the user for text input.

Syntax

prompt("Your message here");

Return Values

User ActionReturns
Entered text + clicked OKThe entered string
Clicked Cancelnull

Example

<script>
  prompt("What is your name?");
</script>
