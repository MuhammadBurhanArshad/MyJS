Even / Odd Number with Loop

Rule

ConditionType
a % 2 === 0Even
a % 2 !== 0Odd

Finding Even Numbers

for (var a = 1; a <= 100; a++) {
    if (a % 2 == 0) {
        document.write(a + " is Even <br>");
    }
}

Finding Odd Numbers

for (var a = 1; a <= 100; a++) {
    if (a % 2 != 0) {
        document.write(a + " is Odd <br>");
    }
}

Both Even and Odd in One Loop

for (var a = 1; a <= 10; a++) {
    if (a % 2 == 0) {
        document.write(a + " → Even <br>");
    } else {
        document.write(a + " → Odd <br>");
    }
}
