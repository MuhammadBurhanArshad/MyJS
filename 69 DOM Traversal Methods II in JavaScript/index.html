JavaScript DOM Traversal Methods II

1. children — DOM Traversal

  • For targeting children elements.
  • For specific children we can use indexing.
var a = document.getElementById("inner").children;
console.log(a);

// Access specific child:
inner.children[0];
inner.children[1];

2. childNodes — DOM Traversal

  • For returning every node like text.
  • It returns every node — element, text, comment.
  • We can also use indexing.
var a = document.getElementById("inner").childNodes;
console.log(a);

// Access specific node:
inner.childNodes[0];
inner.childNodes[1];

Visual Comparison

Given HTML:

<div id="inner">
    <p>One</p>
    <p>Two</p>
    <p>Three</p>
</div>

children sees:

[<p>One</p>, <p>Two</p>, <p>Three</p>]
length = 3

childNodes sees:

[#text, <p>One</p>, #text, <p>Two</p>, #text, <p>Three</p>, #text]
length = 7
⭐ #text entries are whitespace — newlines and indentation between tags.
