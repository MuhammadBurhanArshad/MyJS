JavaScript Math Methods

List of Math Methods

MethodDescription
Math.ceil(x)Rounds up
Math.floor(x)Rounds down
Math.round(x)Rounds to nearest
Math.trunc(x)Removes decimals
Math.max(...)Maximum value
Math.min(...)Minimum value
Math.sqrt(x)Square root
Math.cbrt(x)Cube root
Math.pow(x, y)x to power y
Math.random()Random 0–1
Math.abs(x)Absolute value
Math.PI3.14159...

1. Math.ceil() — Round UP

Math.ceil(2.25);   // 3
// Eliminates decimal, increments
// Works inversely with - values

2. Math.floor() — Round DOWN

Math.floor(2.35);   // 2
// Eliminates decimal, decrements

3. Math.round() — Nearest

Math.round(2.4);   // 2
Math.round(2.5);   // 3

4. Math.trunc() — Remove Decimals

Math.trunc(2.4);   // 2

5. Math.max()

Math.max(8, 10, 2, 50, 25);   // 50

6. Math.min()

Math.min(20, 10, 8, 50, 25);  // 8

7. Math.sqrt()

Math.sqrt(64);    // 8

8. Math.cbrt()

Math.cbrt(125);   // 5

9. Math.pow()

Math.pow(4, 3);   // 64 (4³)

10. Math.random()

Math.random();                     // 0.19xxx
Math.floor(Math.random() * 100);   // 0 to 99
Math.floor(Math.random() * 6) + 1; // 1 to 6

11. Math.abs()

Math.abs(-5.25);   // 5.25

12. Math.PI

Math.PI;   // 3.141592653589793
