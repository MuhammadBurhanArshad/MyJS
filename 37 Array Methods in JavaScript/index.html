JavaScript Array Methods

Built-in methods for sorting, adding, removing, searching, filtering, and iterating.

List of Array Methods

MethodDescription
sort()Sorts the array
reverse()Reverses the order
pop()Removes the last element
push()Adds an element to the end
shift()Removes the first element
unshift()Adds an element to the beginning
concat()Merges two or more arrays
join()Joins elements into a string
slice()Returns a portion
splice()Adds / removes at a position
isArray()Checks if a value is an array
indexOf()First index of a value
lastIndexOf()Last index of a value
entries()Iterator of key/value pairs
every()Tests if ALL pass
filter()Keeps matching elements
find()First matching element
findIndex()Index of first match
includes()Checks if contains
some()Tests if ANY pass
forEach()Runs a function for each
toString()Converts to string
valueOf()Returns the array itself
fill()Fills with a static value

sort() Example

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
a.sort();
// ["Aman", "Burhan", "Rehman", "Sanjay"]

reverse() Example

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
a.reverse();
// ["Rehman", "Burhan", "Aman", "Sanjay"]
