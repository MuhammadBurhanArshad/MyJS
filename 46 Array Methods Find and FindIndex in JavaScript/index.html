Array Methods find() & findIndex()

Target Methods

  • find() — returns the first matching value
  • findIndex() — returns the index of the first match

1. find() Function

Returns the value of the first element in an array that passes a test.

var ages = [10, 23, 19, 20];
var b = ages.find(checkAdult);

document.write(b);

function checkAdult(age) {
    return age >= 18;
}

// Output: 23
⭐ find() only returns the FIRST element which passes the condition.

2. findIndex() Function

Returns the index of the first element in an array that passes a test.

var ages = [10, 23, 19, 20];
var b = ages.findIndex(checkAdult);

document.write(b);

function checkAdult(age) {
    return age >= 18;
}

// Output: 1

More Examples

Find a String

var names = ["Sanjay", "Aman", "Burhan"];
names.find(n => n === "Aman");
// "Aman"

Find an Object

var users = [
    { name: "Ali", age: 22 },
    { name: "Sara", age: 17 },
    { name: "Burhan", age: 25 }
];

users.find(u => u.age >= 18);
// { name: "Ali", age: 22 }

Find Index of a Number

var nums = [5, 12, 8, 130, 44];
nums.findIndex(n => n > 10);
// 1  (12 > 10)
