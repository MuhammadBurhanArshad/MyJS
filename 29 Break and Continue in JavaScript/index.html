JavaScript Break and Continue Statement

Used inside loops to control their flow.

Key Differences

KeywordPurpose
breakExits the loop completely
continueSkips the current iteration
➡ continue is for continue loop (skip current iteration).
➡ break is for breaking loop (exit the loop entirely).

1. Break Example

for (var a = 1; a <= 10; a++) {
    if (a === 3) {
        break;
    }
    document.write("Hello " + a + "<br>");
}

Output: Hello 1, Hello 2 (loop ends when a === 3)

2. Continue Example

for (var a = 1; a <= 5; a++) {
    if (a === 3) {
        continue;
    }
    document.write("Hello " + a + "<br>");
}

Output: Hello 1, Hello 2, Hello 4, Hello 5 (3 is skipped)

Visual Comparison

Break

Iteration 1 → run
Iteration 2 → run
Iteration 3 → ❌ BREAK (loop stops)

Continue

Iteration 1 → run
Iteration 2 → run
Iteration 3 → ⏭️ SKIP
Iteration 4 → run
Iteration 5 → run

Common Use Cases

  • break: searching, exiting menus, limiting iterations
  • continue: skipping invalid values, filtering
