JavaScript Function with Parameters

Parameters allow you to pass values into functions.

Parameter = variable in the function definition
Argument = actual value passed at call time

Syntax

function functionName(parameter1, parameter2) {
    statement
}

functionName(argument1, argument2);

Example — sum(a, b)

function sum(a, b) {
    document.write(a + b);
}

sum(10, 20);   // 30
sum(20, 30);   // 50

More Examples

Greet by Name

function greet(name) {
    document.write("Hello, " + name + "!");
}

greet("Burhan");   // Hello, Burhan!
greet("Ali");      // Hello, Ali!

Multiply Two Numbers

function multiply(x, y) {
    document.write(x * y);
}

multiply(5, 4);    // 20
multiply(10, 3);   // 30
