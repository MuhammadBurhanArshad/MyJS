JavaScript Alert Box

Displays a popup dialog with a message and an OK button.

Syntax

alert("Your message here");

Example

<script>
  alert("Burhan Arshad");
</script>

Click to Trigger the Alert

Key Points

  • Built-in browser function
  • Takes a string as argument
  • Has a single OK button
  • Blocks page until the user clicks OK

alert() vs confirm() vs prompt()

FunctionPurpose
alert()Message with OK
confirm()Message with OK / Cancel
prompt()Asks for text input
