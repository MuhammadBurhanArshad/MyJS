JavaScript Do/While Loop

Runs the body first, then checks the condition. Guaranteed to run at least once.

⭐ In a do while loop, the first time the condition is NOT checked. It checks the condition from the 2nd time onwards.

Do/While Loop Syntax

var a = 1;

do {
    document.write("Burhan");
    a = a + 1;   // (a++)
} while (a <= 10);

Difference Between while and do/while

Featurewhiledo/while
Condition checkedBefore bodyAfter body
Body runs0 or more timesAt least once
When to useCondition may be false initiallyBody must run at least once

Example — Runs At Least Once

var a = 100;

do {
    document.write("This runs once");
    a++;
} while (a <= 10);

Even though 100 <= 10 is false, the body runs once.
