JavaScript Functions

A function is a reusable block of code that performs a specific task.

Without Functions vs With Functions

❌ Without Functions

document.write("Burhan");
- - -
document.write("Burhan");
- - -
document.write("Burhan");

✅ With Functions

function myName() {
    document.write("Burhan");
}

myName();
- - -
myName();
- - -
myName();
A function is used for removing unnecessary code and reducing code/file size.

Function Syntax

Defining a Function

function functionName() {
    statement
}

Calling a Function

functionName();

Example

function greet() {
    document.write("Burhan");
}

greet();   // Burhan
greet();   // Burhan
greet();   // Burhan

Why Use Functions?

  • Reusability — write once, use many times
  • Reduces code size — no repetition
  • Easier maintenance
  • Better readability
  • Modularity
