Array Methods slice() & splice()

Target Methods

  • slice() — extract a portion
  • splice() — add/remove in place

1. slice() Method

Takes a slice from an array by start and end indexing.

Syntax

var newArray = arrayName.slice(startIndex, endIndex);

(endIndex is EXCLUSIVE — not included)

Example

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
var b = a.slice(1, 3);
// b → ["Aman", "Burhan"]
⭐ slice() takes a slice from an array by start and end indexing.
Original array is unchanged.

2. splice() Method

Used for adding values by giving: index, number of deletes, and value.

Syntax

arrayName.splice(index, deleteCount, "new value");

Example — Add Value

var a = ["Sanjay", "Aman", "Burhan"];
a.splice(2, 0, "Rehman");
// a → ["Sanjay", "Aman", "Rehman", "Burhan"]

Example — Delete Values

var a = ["Sanjay", "Aman", "Burhan", "Rehman"];
a.splice(1, 2);
// a → ["Sanjay", "Rehman"]

Example — Replace Value

var a = ["Sanjay", "Aman", "Burhan"];
a.splice(1, 1, "Rehman");
// a → ["Sanjay", "Rehman", "Burhan"]
⭐ splice() is for adding a value by giving index location, number of deletes, and value.
It mutates the original array and returns the removed elements.
