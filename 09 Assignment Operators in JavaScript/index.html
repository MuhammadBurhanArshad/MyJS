JavaScript Assignment Operators

Used to assign values to variables. Compound operators combine arithmetic with assignment.

Different Types of Assignment Operators

OperatorExampleSame As
=x = yx = y
+=x += yx = x + y
-=x -= yx = x - y
*=x *= yx = x * y
/=x /= yx = x / y
%=x %= yx = x % y
**=x **= yx = x ** y

Basic Example

var a = 10;
var b = 20;
a += b;

document.write(a);   // 30
