JavaScript Multi Dimensional Array

An array inside an array — used for tables, matrices, and records.

What is a Multi Dimensional Array?

A multi dimensional array is used for making an array in array.

Syntax

var a = [
    ["Harray", 18, "Male", "B.Com"],
    ["Sunny",  19, "Male", "BCA"],
    ["Burhan", 18, "Male", "CS"]
];

Visual Layout

         0         1        2        3
     ┌─────────┬──────┬────────┬──────────┐
0    │ Harray  │ 18   │ Male   │ B.Com    │
1    │ Sunny   │ 19   │ Male   │ BCA      │
2    │ Burhan  │ 18   │ Male   │ CS       │
     └─────────┴──────┴────────┴──────────┘

Accessing Values

a[0][0]   // "Harray"
a[0][1]   // 18
a[1][0]   // "Sunny"
a[2][3]   // "CS"

Array Length

a.length       // 3  (outer — rows)
a[0].length    // 4  (inner — columns)
a.length is for taking the length of an array.

Traversing with Nested Loops

for (var row = 0; row < a.length; row++) {
    for (var col = 0; col < a[row].length; col++) {
        document.write(a[row][col] + " ");
    }
    document.write("<br>");
}
