Array Method forEach()

Targeted Method

  • forEach() — loops through an array with a function

Array-forEach() Function

⭐ Use for printing an array with sequence.
⭐ It's a shorter way to print an array.

Syntax

arrayName.forEach(function (value) {
    statement
});

Example

var a = ["Sanjay", "Aman", "Burhan"];

a.forEach(function (value) {
    document.write(value + "<br>");
});

// Output:
// Sanjay
// Aman
// Burhan

Function — Inline or Outer

We can make function in forEach, or make outer function in it.

Inline

a.forEach(function (value) {
    document.write(value + "<br>");
});

Outer Function

function show(value) {
    document.write(value + "<br>");
}

a.forEach(show);

Arrow Function

a.forEach(value => document.write(value + "<br>"));

Using Index

a.forEach(function (value, index) {
    document.write(index + ": " + value + "<br>");
});

// Output:
// 0: Sanjay
// 1: Aman
// 2: Burhan
