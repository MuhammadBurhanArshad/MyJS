JavaScript Comments

Comments are ignored by the JavaScript engine. There are 2 types:

  1. Single Line — //
  2. Multiple Line — /* ... */

1. Single Line Comment

<script>
  document.write("Burhan"); // Comment
</script>

2. Multiple Line Comment

<script>
  document.write("Burhan"); /* This is
  Multiple line Comment */
</script>

Comparison

TypeSymbolUse Case
Single Line//Short notes
Multiple Line/* ... */Long descriptions / block disable
