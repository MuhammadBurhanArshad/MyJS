JavaScript Conditional (Ternary) Operator

A shorthand for the if else statement.

Flow

Conditions → False → Statement2
    ↓
   True
    ↓
Statement1

Syntax

(condition) ? true_statement : false_statement;
⚠️ The ternary operator only supports two statements — one for true and one for false.

Example

var x = 15;
var z;

(x > 10) ? z = "True" : z = "False";

document.write(z);

Comparison with if else

// if else version
if (x > 10) {
    z = "True";
} else {
    z = "False";
}

// ternary version
(x > 10) ? z = "True" : z = "False";
