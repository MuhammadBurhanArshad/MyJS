JavaScript DOM Targeting Methods

DOM targeting = selecting HTML elements so you can work with them.

Additional Operations

  • Add HTML Element
  • Delete HTML Element

How to Target a DOM Object

⭐ These three are the basic and most important methods of DOM targeting.

1. getElementById

var element;
element = document.getElementById("Burhan");
console.log(element);

2. getElementsByClassName

var element;
element = document.getElementsByClassName("Burhan");
console.log(element);

3. getElementsByTagName

var element;
element = document.getElementsByTagName("Burhan");
console.log(element);

Other DOM Targeting Methods

PropertyDescription
documentThe whole document
document.allAll elements as an array
document.documentElementThe <html> element
document.headThe <head> element
document.titleThe <title> text
document.bodyThe <body> element
document.imagesAll <img> elements
document.anchorsAll <a> with name
document.linksAll <a> links
document.formsAll <form> elements
document.doctypeThe DOCTYPE node
document.URLFull URL
document.baseURIBase URL
document.domainDomain name
