Modify and Remove Array Element

1. Modify Array Element

Assign a new value to an index:

var a = ["Burhan", 17, "BBA"];
a[1] = 18;
IndexBeforeAfter
0"Burhan""Burhan"
11718
2"BBA""BBA"

2. Remove Array Element

Use the delete keyword:

var a = ["Burhan", 18, "BCA"];
delete a[1];
IndexBeforeAfter
0"Burhan""Burhan"
118undefined
2"BCA""BCA"
⚠️ Important: delete does NOT shift the remaining elements. It leaves an empty slot (undefined) at that index.

delete vs splice

MethodEffectLength
delete a[1]value → undefinedsame
a.splice(1, 1)removed, shift−1

Complete Example

var a = ["Burhan", 17, "BBA"];

a[1] = 18;        // modify
delete a[2];      // remove

// a → ["Burhan", 18, undefined]
