JavaScript Switch Statement

Selects one block from many based on a value. A cleaner alternative to long if else if chains.

Syntax

switch (expression) {
    case condition1:
        statement(s);
        break;

    case condition2:
        statement(s);
        break;

    case condition3:
        statement(s);
        break;

    default:
        statement(s);
}

Parts of a Switch

PartPurpose
switch (expression)Value to be evaluated
case value:A possible match
break;Stops execution and exits the switch
default:Runs if no case matches

Example — Day of the Week

var day = 3;

switch (day) {
    case 1: document.write("Monday");    break;
    case 2: document.write("Tuesday");   break;
    case 3: document.write("Wednesday"); break;
    case 4: document.write("Thursday");  break;
    default: document.write("Unknown day");
}
⚠️ Don't forget break; — otherwise the code "falls through" to the next cases.
