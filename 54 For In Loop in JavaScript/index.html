JavaScript For/In Loop

Target

  • for/in loop — iterate over object properties

How to Print Objects

var a = {
    fname: "Burhan",
    lname: "Arshad",
    age: 18
};

console.log(a.fname);
console.log(a.lname);
console.log(a.age);

How to Print Objects with a Loop

Syntax

for (var key in obj) {
    statement
}

Example

var obj = {
    fname: "Burhan",
    lname: "Arshad",
    age: 18
};

for (var key in obj) {
    document.write(obj[key]);
}

// Output: BurhanArshad18
⭐ For loop is for printing object.
⭐ For printing the key of an object, we use key + before the object variable.

Print Key + Value

for (var key in obj) {
    document.write(key + " = " + obj[key] + "<br>");
}

// Output:
// fname = Burhan
// lname = Arshad
// age = 18

for...in on an Array

var arr = ["Sanjay", "Aman", "Burhan"];

for (var i in arr) {
    document.write(i + ": " + arr[i] + "<br>");
}

// Output:
// 0: Sanjay
// 1: Aman
// 2: Burhan
