Array Method filter()

Target Method

  • filter() — creates a new array with elements that pass a test

Array-filter() Function

Checks an array by a given condition and makes a new array.

⭐ filter() creates an array filled with all array elements that pass a test.

Syntax

arrayName.filter(functionName);

Example

var ages = [80, 12, 19, 20];
var b = ages.filter(checkAdult);

document.write(b);

function checkAdult(age) {
    return age >= 18;
}

// Output: 80,19,20

How It Works

ages = [80, 12, 19, 20]
         ↓   ↓   ↓   ↓
>= 18?   ✅  ❌  ✅  ✅
         ↓       ↓   ↓
Result = [80, 19, 20]   ← new array

Even Numbers Example

var nums = [1, 2, 3, 4, 5, 6];

var evens = nums.filter(function (n) {
    return n % 2 === 0;
});

// evens → [2, 4, 6]

Arrow Function Version

var ages = [80, 12, 19, 20];

var adults = ages.filter(age => age >= 18);

// adults → [80, 19, 20]

filter() vs find()

MethodReturnsMatching
filter()New arrayAll matches
find()Single elementFirst match only

What If Nothing Matches?

[10, 12, 15].filter(n => n >= 18);
// []  (empty array)
