Array Methods some() & every()

Target Methods

  • some() — checks if any element matches
  • every() — checks if all elements match
⭐ This method needs a function.
⭐ Returns true or false.

1. some() Function

Checks if any of the elements in an array match or pass a test.

var ages = [10, 13, 15, 20];
var b = ages.some(checkAdult);

document.write(b);

function checkAdult(age) {
    return age >= 18;
}

// Output: true  (because 20 >= 18)

2. every() Function

Checks all values of an array for a given condition.

var ages = [10, 13, 18, 20];
var b = ages.every(checkAdult);

document.write(b);

function checkAdult(age) {
    return age >= 18;
}

// Output: false  (because 10 < 18)

some() vs every()

MethodReturns TRUE when…Returns FALSE when…
some()At least one passesNone pass
every()All passAt least one fails

More Examples

some() — At Least One Even

[1, 3, 5, 8].some(n => n % 2 === 0);   // true

every() — All Even

[2, 4, 6, 8].every(n => n % 2 === 0);  // true

every() — Fails

[2, 4, 5, 8].every(n => n % 2 === 0);  // false  (5 is odd)
