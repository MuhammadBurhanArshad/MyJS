Add HTML Tags in JavaScript

1. The <script> Tag

All JavaScript code lives inside the <script> tag:

<script>
  // JavaScript code here
</script>

2. document.write() Method

Writes text or HTML directly to the page:

document.write("<h1>Muhammad Burhan</h1>");
document.write("<b>Muhammad Burhan</b>");

4. Common HTML Tags You Can Write

  • <h1> – <h6> — Headings
  • <b> — Bold text
  • <i> — Italic text
  • <u> — Underline
  • <p> — Paragraph
  • <br> — Line break
  • <a> — Hyperlink
  • <img> — Image
